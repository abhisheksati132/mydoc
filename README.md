## Find it. Read it. Get it done.

| When you need to… | MyDoc gives you… |
| --- | --- |
| **Find a file fast** | Pinned folders, saved searches, document and media categories, date-grouped photos, quick previews, and browsing inside ZIP archives. |
| **Pick up your reading** | PDF, Word, Excel, PowerPoint, EPUB, and text viewing, with recent documents, reading positions, and format-specific controls. Add the optional Office engine for enhanced layouts. |
| **Get a PDF ready to send** | Scan pages, merge selected PDFs directly from Library, reorder pages, compress, add a signature, or extract text from a scan with on-device OCR. |
| **Play something** | A local media viewer with video tracks, external subtitles, speed controls, A–B looping, a queue, and direct HTTPS video playback. |
| **See what fills your phone** | A storage breakdown, installed-app and APK views, and cleanup suggestions you can review file by file. Move supported files to Recycle Bin so they can be restored. |

## A workspace that feels like MyDoc

Ink & Seal pairs warm paper, graphite, Inter typography, and a teal seal with Material 3 Expressive motion. Find the same controls in familiar places across Library, Tools, and the readers. Choose light, dark, or AMOLED black and adjust glass and motion in Settings.

Local reading and core document tools run on your device. Office support is a separate, optional download from **Settings → Reading**. Office viewing fidelity varies by format and engine.

## Get MyDoc for Android

1. Open [GitHub Releases](https://github.com/abhisheksati132/mydoc/releases/latest).
2. Download **ARM64** for a compatible 64-bit ARM phone. Choose **universal** if you are unsure which build fits.
3. Open the APK and follow Android’s installation prompts. Signed APKs and matching SHA-256 files are listed together.

Already using MyDoc? Use **Settings → About** to check for updates.
