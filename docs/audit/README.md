# Audit snapshots

These files are historical records of security and quality reviews, written in
October–November 2026 against earlier builds (down to MuPDF 1.24.4). Every finding
listed here was triaged at the time; the fix batches in
[FIX_PLAN.md](FIX_PLAN.md) are marked complete.

They are published for transparency and are **not** a description of the current
build. Treat any claim here as a snapshot to re-verify against today's code before
acting on it.
